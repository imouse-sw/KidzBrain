# KidzBrain
Proyecto desarrollado por alumnos del CECyT No. 9 para quinto semestre.
Es una plataforma educativa gamificada diseñada para apoyar y complementar la educación primaria en México. El proyecto busca combatir el rezago educativo y la falta de motivación en los niños transformando el aprendizaje en una experiencia divertida y significativa.
Nuestra aplicación tiene como objetivo principal ofrecer contenidos interactivos en materias clave como matemáticas, ciencias y lenguaje, a través de juegos y dinámicas lúdicas. Esto permite que los niños refuercen sus conocimientos y desarrollen un gusto por aprender.
